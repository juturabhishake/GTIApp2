## 🚀 Project Setup (Quick Start Guide)

Get the project running locally in 4 simple commands:

```bash
# 1. Clone the repository from GitHub
git clone https://github.com/juturabhishake/GTIApp2.git
cd GTIApp2

# 2. Install all dependencies using pnpm
pnpm install

# 3. Verify project health and dependency compatibility (20/20 checks)
npx expo-doctor --verbose

# 4. Start the local Metro bundler development server
pnpm start
```

*Open the **Expo Go** app on your Android device and scan the terminal QR code to view the live app instantly!*

## 🔍 Exhaustive File-by-File Technical Deep Dive

### 1. Configuration & Root Files
* **`package.json`**: Manifest declaring `gtiapproject` (v1.0.0), scripts (`pnpm start`, `pnpm run android`, `pnpm apk:android`), dependencies, and points the main entry to `"main": "expo-router/entry"`.
* **`app.json`**: Native manifest configuring app name (`GTI Production App`), slug (`GTIAppProject`), scheme (`myapp`), Android package name, and native permissions (`CAMERA`, `ACCESS_FINE_LOCATION`, `ACCESS_COARSE_LOCATION`).
* **`eas.json`**: Build configuration for Expo Cloud. Configures `development`, `preview` (standalone APK), and `production` (optimized APK/AAB).
* **`metro.config.js`**: Extends `expo/metro-config` to bundle SVG assets, fonts, and packages like `xlsx` cleanly.
* **`tsconfig.json`**: Strict TypeScript setup defining `@/*` absolute path imports.

### 2. App Routing & Screens (`app/` Directory)
* **`app/_layout.tsx`**: Root layout that loads custom fonts (`SpaceMono`), hides the splash screen when ready, wraps the app in `ThemeProvider`, and renders the `<Stack>`.
* **`app/+not-found.tsx`**: 404 screen rendering a fallback message and a link back to `/` if an invalid route is accessed.
* **`app/(tabs)/_layout.tsx`**: Defines the bottom navigation tabs, sets custom active/inactive tint colors, registers icons via `IconSymbol`, and sets tab titles.
* **`app/(tabs)/index.tsx`**: Automatic redirector routing incoming users directly to `/Home`.
* **`app/(tabs)/Home/index.tsx`**: Main operator dashboard. Displays active shift statistics and automatically executes `locationVerifier.ts` to confirm the operator is at the Naidupeta plant.
* **`app/(tabs)/Scanner/index.tsx`**: Hardware barcode/QR code reader utilizing `expo-camera`. Displays a viewfinder reticle and processes scanned values.
* **`app/(tabs)/Orders/index.tsx`**: Production order queue displaying batch IDs, target quantities, and fulfillment status.
* **`app/(tabs)/RejectionEntry.tsx`**: Quality defect tracking screen where operators log rejected parts, machine numbers, defect reasons, and scrap counts.
* **`app/(tabs)/trainingForm/index.tsx`**: Digital training and safety compliance form recording equipment certifications and sign-offs.
* **`app/(tabs)/History/index.tsx`**: Production audit log connected to `ExportExcelButton.tsx` for exporting records to Excel.
* **`app/(tabs)/Settings/index.tsx`**: Operator preferences allowing dark/light theme toggling, cache clearance, and system diagnostics.

### 3. Reusable UI Components (`components/`)
* **`AppScreen.tsx`**: Foundation layout component wrapping content in `SafeAreaView` from `react-native-safe-area-context` to prevent notch overlaps.
* **`CustomHeader.tsx`**: Consistent navigation header supporting dynamic titles, back buttons, and action icons.
* **`ExportExcelButton.tsx`**: Takes structured JSON datasets, applies header styles and column widths via `xlsx-js-style`, writes binary files to `FileSystem.cacheDirectory`, and triggers sharing via `expo-sharing`.
* **`RejectionEntryView.tsx`**: Form component with dropdown selectors, numeric inputs, and validation logic.
* **`ThemedText.tsx` & `ThemedView.tsx`**: Text and view components that dynamically select colors from `Colors.ts` based on active light/dark mode.
* **`ui/IconSymbol.tsx`**: Cross-platform icon mapper using Apple SF Symbols on iOS and Google Material Icons on Android/Web.

### 4. Contexts, Hooks, Utilities & Constants
* **`contexts/ThemeContext.tsx`**: Application-wide state managing `theme` (`'light'` | `'dark'`) and `toggleTheme()`.
* **`utils/locationVerifier.ts`**: Geofencing engine. Queries device GPS coordinates and applies the **Haversine Formula** to verify distance against the **GTI Greentech Industries, Naidupeta Facility**.
* **`constants/Colors.ts`**: Master palette dictionary exporting `Colors.light` and `Colors.dark`.

### 2. Creating a Brand New Screen (Step-by-Step)

#### Step 1: Create the Screen File
Create a new file at: `app/(tabs)/Maintenance/index.tsx`.

#### Step 2: Write the Screen Component Code
```tsx
import React, { useState } from 'react';
import { StyleSheet, TouchableOpacity, ScrollView, Alert } from 'react-native';
import { AppScreen } from '@/components/AppScreen';
import { CustomHeader } from '@/components/CustomHeader';
import { ThemedText } from '@/components/ThemedText';
import { ThemedView } from '@/components/ThemedView';

export default function MaintenanceScreen() {
  const [machineStatus, setMachineStatus] = useState('OPERATIONAL');

  const handleReportBreakdown = () => {
    Alert.alert('Alert Dispatched', 'Maintenance engineers notified for Line 3.');
    setMachineStatus('BREAKDOWN REPORTED');
  };

  return (
    <AppScreen>
      <CustomHeader title="Machine Maintenance" />
      <ScrollView contentContainerStyle={styles.container}>
        <ThemedView style={styles.card}>
          <ThemedText type="subtitle">CNC Press Unit #04</ThemedText>
          <ThemedText style={{ marginVertical: 6 }}>Status: {machineStatus}</ThemedText>
          <ThemedText style={styles.note}>Location: GTI Greentech Industries, Naidupeta</ThemedText>
        </ThemedView>

        <TouchableOpacity style={styles.button} onPress={handleReportBreakdown}>
          <ThemedText style={styles.buttonText}>Report Machine Breakdown</ThemedText>
        </TouchableOpacity>
      </ScrollView>
    </AppScreen>
  );
}

const styles = StyleSheet.create({
  container: { padding: 16 },
  card: { padding: 16, marginBottom: 16, borderRadius: 8 },
  note: { fontSize: 13, opacity: 0.7 },
  button: { backgroundColor: '#dc2626', padding: 14, borderRadius: 8, alignItems: 'center' },
  buttonText: { color: '#ffffff', fontWeight: 'bold' }
});
```

#### Step 3: Register in the Tab Bar (`app/(tabs)/_layout.tsx`)
```tsx
<Tabs.Screen
  name="Maintenance/index"
  options={{
    title: 'Maintenance',
    tabBarIcon: ({ color, focused }) => (
      <IconSymbol size={24} name={focused ? "wrench.fill" : "wrench"} color={color} />
    ),
  }}
/>
```

#### Step 4: Navigate from Any Screen
```tsx
import { useRouter } from 'expo-router';

const router = useRouter();
router.push('/Maintenance');
```

### Fixing the Gradle Timeout Error (`pnpm apk:android`)
When running local builds via `pnpm apk:android`, Gradle may throw:
`java.io.IOException: Downloading from https://services.gradle.org/distributions/gradle-9.4.1-bin.zip failed: timeout (10000ms)`

* **Fix Option 1 (Manual Download):** Download `gradle-9.4.1-bin.zip` manually and paste it into `%USERPROFILE%\.gradle\wrapper\dists\gradle-9.4.1-bin\<hash_folder>\`.
* **Fix Option 2 (Increase Timeout):** Run in PowerShell before building:
  ```powershell
  $env:GRADLE_OPTS="-Dorg.gradle.internal.http.socketTimeout=120000"
  pnpm apk:android
  ```
* **Fix Option 3 (EAS Cloud Build - Recommended):** Offload compilation to Expo's high-speed build servers.

## 🩺 Complete Expo Doctor Diagnostic Guide (All 20 Checks Explained)

| # | Check Name | Why This Check Fails | Exact Command & Solution |
| :-: | :--- | :--- | :--- |
| **1** | **Check for common project setup issues** | Missing root files (`package.json`, `app.json`), broken JSON syntax. | Ensure valid JSON in `package.json` and `app.json`. |
| **2** | **Check local environment files not committed** | `.env` files with secret keys are not git-ignored. | Add `.env*` to `.gitignore` and run `git rm --cached .env`. |
| **3** | **Check package.json for common issues** | Missing or incorrect `"main"` field. | Ensure `"main": "expo-router/entry"` in `package.json`. |
| **4** | **Check Expo config for common issues** | Missing `"name"` or `"slug"` in `app.json`. | Verify required fields in `app.json`. |
| **5** | **Check for overridden dependencies** | Unsupported package overrides in `package.json`. | Remove conflicting override blocks and run `pnpm install`. |
| **6** | **Check for lock file** | Missing or multiple conflicting lockfiles. | Delete extra lockfiles and run `pnpm install`. |
| **7** | **Check dependencies not installed directly** | Internal packages installed directly in dependencies. | Remove via `pnpm remove <package-name>`. |
| **8** | **Check for issues with Metro config** | `metro.config.js` does not extend `expo/metro-config`. | Use `getDefaultConfig(__dirname)` from `expo/metro-config`. |
| **9** | **Check npm/yarn/pnpm versions** | Package manager is outdated. | Update pnpm via `pnpm self-update` or `npm i -g pnpm`. |
| **10** | **Check native tooling versions** | Node.js version is obsolete (e.g. Node 16). | Install Node.js LTS (v20+ or v22+) from [nodejs.org](https://nodejs.org). |
| **11** | **Check app config in non-CNG project** | Native folders present but `app.json` properties unsynced. | Cleanly regenerate native files: `npx expo prebuild --clean`. |
| **12** | **Check submission requirements** | Missing package name or app store icons. | Configure `"android": { "package": "com.company.app" }`. |
| **13** | **Check required peer dependencies** | A package requires a missing peer dependency. | Install missing peer: `npx expo install <package>`. |
| **14** | **Check Expo config schema** | Typo or invalid property name inside `app.json`. | Match official Expo schema property names. |
| **15** | **Check package versions match SDK** | Installed package versions mismatch Expo SDK 58. | Automatically fix versions: `npx expo install --fix`. |
| **16** | **Check no duplicate dependencies** | Multiple different versions of `react` or `react-native`. | Deduplicate packages: `pnpm dedupe`. |
| **17** | **Validate against React Native Directory** | Library is deprecated or lacks New Architecture support. | Replace with actively maintained Expo-recommended package. |
| **18** | **Check native modules support packages** | Legacy Android Support libraries instead of AndroidX. | Add `android.useAndroidX=true` in `gradle.properties`. |
| **19** | **Check @expo/vector-icons conflict** | Standalone `react-native-vector-icons` conflicting. | Remove conflicting library: `pnpm remove react-native-vector-icons`. |
| **20** | **Check for legacy global CLI** | Obsolete global `expo-cli` installed. | Uninstall legacy package: `npm uninstall -g expo-cli`. |
